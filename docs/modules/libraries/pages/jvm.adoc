= JVM
:description: Use the Neo4j Ontology Graph Specification library from Kotlin, Java and other JVM languages.

Requires Java 11 or later.

== Install

[.tabs]
.Gradle
[source,kotlin,subs="attributes+"]
----
implementation("org.neo4j.spec.graph:ontology-graph-spec:{library-version}")
----

.Maven
[source,xml,subs="attributes+"]
----
<dependency>
    <groupId>org.neo4j.spec.graph</groupId>
    <artifactId>ontology-graph-spec</artifactId>
    <version>{library-version}</version>
</dependency>
----

== Read and write models

`GraphSpec.Json` and `GraphSpec.Yaml` read and write models. Reading expands any xref:format:shorthand.adoc[shorthand].

[.tabs]
.Kotlin
[source,kotlin]
----
import org.neo4j.spec.graph.GraphSpec

val model = GraphSpec.Yaml.decodeFromString(yaml)
val json = GraphSpec.Json.encodeToString(model)
----

.Java
[source,java]
----
import org.neo4j.spec.graph.GraphSpec;
import org.neo4j.spec.graph.model.GraphModel;

GraphModel model = GraphSpec.getYaml().decodeFromString(yaml);
String json = GraphSpec.getJson().encodeToString(model);
----

== Customise the library

`GraphSpec` builds a configured copy of `GraphSpec.Json` or `GraphSpec.Yaml`. From Java, `GraphSpecs.graphSpec` takes a `Consumer` so no `Unit` needs returning.

[.tabs]
.Kotlin
[source,kotlin]
----
import org.neo4j.spec.graph.GraphSpec

val spec = GraphSpec(GraphSpec.Json) {
    json { prettyPrint = false }
}
----

.Java
[source,java]
----
import org.neo4j.spec.graph.GraphSpec;
import org.neo4j.spec.graph.GraphSpecs;

GraphSpec spec = GraphSpecs.graphSpec(GraphSpec.getJson(), builder ->
    GraphSpecs.json(builder, json -> json.setPrettyPrint(false)));
----

== Validate models

[.tabs]
.Kotlin
[source,kotlin]
----
import org.neo4j.spec.graph.validate.Validations

val issues = model.validate(Validations.core)
----

.Java
[source,java]
----
import org.neo4j.spec.graph.validate.Issue;
import org.neo4j.spec.graph.validate.Validations;

List<Issue> issues = model.validate(Validations.getCore());
----

See xref:validation.adoc[] for the validator sets and issues.

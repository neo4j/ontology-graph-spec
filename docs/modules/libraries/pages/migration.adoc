= Migration
:description: Convert models between the Neo4j Ontology Graph Specification and Aura Data Importer formats.

Migration converts models between this specification and the Aura Data Importer formats, in as many steps as needed.

[cols="1,3,2,1"]
|===
| Type | Format | Read | Write

| `graph_spec` | This specification | 1.0.0, 1.1.0 | 1.1.0
| `data_model` | Aura Data Importer graph data model | 2.3.0, 2.4.0, 3.0.0 | 3.0.0
| `data_model_wrapped` | Aura Data Importer model file, which wraps the data model with user interface
information | 2.3.0, 2.4.0, 3.0.0 | 3.0.0
|===

The version of a document is read from the document: from the `schema` URL for this specification, and from the data
model's `version` field for the Aura Data Importer formats.
